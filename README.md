# TrioWire Preview

The fully storyboarded, all-static preview of the TrioWire product — every page
present, fully navigable, with mocked data throughout. The preview is the
wireframe deliverable: numbered acceptance criteria in the Run Book bind to
these pages.

**Start here:** [sitemap.html](sitemap.html) — every page and its connections.

- Live (project URL): https://timbierowicz.github.io/triowire-preview/
- Live (custom domain): https://triowire-preview.imbwaite.com/

Built on one shared library (`assets/preview-lib.css`) — every page composes
from it and carries no styling of its own.
