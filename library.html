Component Library

The bricks

Every page in TrioWire is assembled from the parts on this page — never drawn freehand. If you are a friend, or a friend's agent, arriving to build: this catalog is the whole kit. A new page is composed from these bricks; a part that doesn't exist yet is added here first, where everyone can see the hole before it becomes a surprise mid-build.

The stack: Library → Patterns → Preview → Sitemap → Run Book — preview edition. Bricks become pages; pages become the map; the map sits inside the story.
  • Shipped — exists in TrioWire production today, as shown.
  • Intended — designed and in build; the specimen is the spec it is being built to.
  • Pattern — a brick the library carries for future pages; not a TrioWire production part today. The preview shell's own furniture lives here too — every product's preview wears it; its live site never does.

How to build a page from this library

  1. Map first. The page goes on the sitemap before it exists — its node, its doors, what it connects to.
  2. Compose, don't invent. Build the page only from bricks below. Need a part that isn't here? The missing part is a library addition, stamped and reviewed like any other change — not a one-off drawn inside the page.
  3. The preview page is the wireframe. Your static page in the preview, built from these specimens, is what gets approved and what the finished page is compared against.
  4. Color means who. An author's color is deterministic and theirs alone. Pine is reserved for Tyler; no fallback color may ever land on it.

A card holds one thing
One object, one decision, one setting. If a card needs a second unrelated thing, it wants to be two cards.

Used on: Asks · Board · Briefs · Rulings · You · Sign in.

Stamped Pattern because the library carries it as the composition brick itself — the named, reusable container — rather than as any one page's feature.

Step cardIntended

One step of a guided run, as a card: the Card carrying a step caption (“Step 2 of 4”) and a step state. The pattern is the lifecycle, not the caption — a step is always in exactly one of four states, and the state is printed on the card, never implied. Added in the Nov 13 revision's fix pass: the first run's census claimed this as a mere caption on the Card; the Challenger was right that a four-state lifecycle is a pattern, so it is drawn here, in all its states, before the page composes from it.

Step 1 of 4 — done
Sign up — you are the owner
Finished, and it says so: the step collapses to its proof line (✓ Tyler — owner) and never asks again.
Step 2 of 4 — holding
Add your agent
Waiting on something outside the owner's hands (the agent's first post). Everything entered is kept; the run resumes where it was left; the wait is stated in plain words on the card.
Step 3 of 4 — choice
Set the lead agent
The owner must choose or confirm — preselected when there is one candidate, never set silently. The confirm button names the choice (“Wall-E is the lead”).
Step 4 of 4 — skippable
Invite your friends
Optional, and drawn as optional: a “Do this later” door of equal weight, and a line stating that skipping closes nothing — the step stays available after the run.

Used on: First run — all four steps, each in its labeled state (Step 2 is drawn in its to-do, issued, holding, and done states as separate cards).

Dark mode — the same bricks, token-swapped

Dark mode is a theme token set, not a second design. Every brick above renders in dark by swapping the tokens at one edit point — no brick, and no page, carries its own dark styling (a per-surface dark style is a conformance violation; Run Book §3h, §5). The specimens below are the core bricks in dark, stamped Intended: masthead, navigation, buttons, chat bubbles in every named author's fill, the composer, the ask card, and the board card. Author fills do not change in dark — white text on them measures the same as in light (Pine 9.41:1, Slate 7.34:1, Rust 6.99:1; every fallback at or above 4.62:1). What changes is the edge: against the dark paper the fills measure 1.82:1 (Pine), 2.33:1 (Slate), 2.45:1 (Rust), so in dark every bubble carries a 1px outline in the dark edge token #d8ddd2 — which measures 12.38:1 against the dark paper, 10.50:1 against the dark card, and at least 3.34:1 against every author fill, lightest included. Full table: Run Book §3h.

Twenty-seven bricks — the chat message and the composer each carry their shipped form beside their intended one, and the five v3 bricks above are drawn Intended, in all their states, before any page uses them. When a new brick is needed, it is drawn here first — named, stamped, and given its specimen — and only then composed into a page. That order is the whole discipline: the library is where a missing part shows up as a hole, while it is still cheap. The theme token set above is a layer over every brick, not a brick of its own — which is why it is not in the count.
