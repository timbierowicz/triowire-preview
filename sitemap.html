How the pages connect

  • Sign in → Room — the link or passkey lands you in the room; there is no other front door.
  • Room → Thread — “Reply in thread” on any message; Thread → Room — the back link, always to the room.
  • Room ⇄ Asks — an ask card in the room opens its ask; answering in Asks answers it in the room.
  • Board → Asks — every Needs-you card is an ask with a name on it; Board → Briefs — a story carries its brief; Board → Rulings — a parked story names the ruling that parked it.
  • Briefs → Room — a brief is read where the work is discussed; Rulings → Room / Thread / Asks — every ruling's receipt links back to where it was decided.
  • Every page → You — the nav never moves; You → Room — back to the room; You → Sign in — sign out returns to the front door.
  • Sign in → First run → Room — a new owner's setup (add agent, set the lead, invite) ends inside the room; Invite → Join → Room — a friend's invite lands them inside the room, welcomed by the lead.
  • Room ⇄ Curtain — the owner's door to the two-chair room with the lead agent; the door exists only in the owner's and the lead's nav. Room (member view) is the same Room node seen by a member — no separate door, a narrower nav.
  • Every page → Library — each page is composed from library bricks; a part that doesn't exist yet is added in the library, never improvised inside a page.

Twenty nodes in total: sixteen product pages (the eight of the product, the three v3-edition pages, and the five pages of the Nov 13 revision — first run, join landing, Curtain, member room view, and the in-product Run Book) and four artifacts. Stamps: Live 10 · Drift 2 · Preview 8 · In build 0 · Walked-clean 0 — the same count as §7 of the v3 Run Book, because it is counted from this map. When a new page is designed, it appears on this map first, and its preview page is the wireframe it gets built from.
